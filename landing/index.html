Changelog

What's New

Latest enhancements to TRAKSHYA WAF.

v2.2

Cross-Platform WAF · Real Traffic Inspection · Browser Dashboard

Full WAF pipeline: Client → WAF Proxy (8080) → Upstream (3000). Traffic generator sends real HTTP requests through the WAF proxy for live attack demonstration. Cross-platform start scripts for Windows, macOS, and Linux. Dashboard runs in your browser — no Electron required. Auto-start on boot support. Titlebar buttons (Refresh, Minimize, Exit).

v2.1

DuckDB Analytics · 3 New Attack Modules · Kubernetes

Live event pipeline with DuckDB persistence. SSRF, CRLF injection, and JNDI/Log4Shell rules. Evasion detection (double URL decode, HTML entities, full-width Unicode). Helm chart with Recreate strategy for single-writer DB. K8s probes for all deployments.

v2.0

Go API Rewrite · Synthwave Dashboard · 3D Globe

Replaced Node.js mock server with live Go/DuckDB API. Synthwave dashboard with Three.js globe, SIEM correlation engine, 7 theme variants. HIDS + FIM + SCA C daemon. Active response via iptables/nftables/UFW.

v1.0

Initial Release

Rust reverse proxy with 8 attack detection rules (SQLi, XSS, RFI, CMDi, path traversal, LFI, XXE, SSTI). Token bucket rate limiter, circuit breaker, JWT auth, GeoIP blocking. Basic Node.js dashboard with SQLite.

Defense Layers

Enterprise-Grade Protection

Six layers of defense. Everything runs locally on your machine.

Attack Detection

SQLi, XSS, RFI, CMDi, path traversal, LFI, XXE, SSTI, SSRF, CRLF injection, JNDI/Log4Shell — 11 vectors with evasion countermeasures. Regex engine, OWASP CRS compatible.

SIEM Correlation

7 MITRE ATT&CK rules: brute force, port scanning, XSS/SQLi waves, geo anomaly, beaconing, data exfiltration, lateral movement. Slack/Discord webhooks.

HIDS + FIM + SCA

Auth log monitoring, SHA-256 file integrity, CIS benchmark compliance. C daemon reports every 30s via HTTP POST. Runs as systemd service.

Active Response

iptables/nftables IP blocking, UFW integration, 3 posture modes (Monitor / Standard / Under Attack). Systemd lockdown controls.

Live Analytics

DuckDB-powered event pipeline: top attackers timeline, country heatmap, rule trigger stats, configurable retention. WebSocket real-time push to dashboard.

Rule Engine

Regex-based tester with JSON import/export. Create, test, and deploy custom WAF rules. Built-in OWASP CRS with OWASP categories. Live hit counting.

Install

Run in One Command

No cloud accounts. No API keys. Just one line — then open your browser.

$ git clone https://github.com/Pradyu12/TRAKSHYA-WAF.git && cd TRAKSHYA-WAF && ./start-waf.sh copy

Requires Rust (cargo), Go 1.22+, Node.js, and Git. Builds and starts the full WAF stack. Dashboard opens in your browser.
